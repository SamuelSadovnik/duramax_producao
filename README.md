# Duramax Produção

Sistema de produção da Duramax Tintas e Vernizes: o comercial importa o PDF do pedido, o PCP decide o que vira OP, a fábrica acompanha pela TV, o gerente inicia e finaliza as OPs pelo tablet e os gestores acompanham o desempenho.

Instruções completas de instalação e deploy no fim do desenvolvimento.
